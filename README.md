# ApplyPilot

AI job application co-pilot inspired by AIApply — resume builder, ATS scanner, job board, auto-apply simulator, tracker, mock interviews, and Interview Buddy.

## Quick start

```bash
npm install
npm run db:reset
npm run dev
```

Demo login: `demo@applypilot.com` / `demo1234`

See `PLAN.md` for architecture and feature parity notes.
